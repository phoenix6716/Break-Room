PLAYER GUIDE

HOW TO PLAY Clue Ladder

Name familiar things from progressively clearer clues.

1. Read the clues. Each puzzle gives a category and starts with one clue. Type the familiar person, place, thing or idea it describes.

2. Guess or get help. A wrong guess or Next clue unlocks the next hint. Repeating an answer does not cost another clue. On clue five, Reveal answer finishes unsolved for zero.

3. Fewer clues, more points. Solve on clue 1 / 2 / 3 / 4 / 5 for 1,000 / 800 / 600 / 400 / 200 points. There is no timer, speed penalty, multiplier, lives or elimination.

4. Five Daily puzzles. Maximum 5,000 native points. Arcade score = points ÷ 50. Completed Dailies count towards stats, Profile and Friends. Everyone gets the same Sydney-date set, resetting at midnight Australia/Sydney. Input, hints and frozen puzzles save as you go.

5. Answer checking. Common alternative names, punctuation, accents and minor typos in longer names are accepted. Generic fragments and repeated words are not enough. Fixed local rules check your answer, with no AI service.

6. Unlimited. Practise free from 300 puzzles, excluding today's Daily set. Eligible answers do not repeat until the pool is exhausted. Topic changes apply next puzzle. Practice resumes in this tab and stays separate from Daily/cloud records.
