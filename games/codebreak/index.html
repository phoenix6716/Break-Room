HOW TO PLAY Codebreak

Find the four-digit secret code. You have eight guesses and no timer.

1. Try a code. Enter four digits using 1–6. Digits can repeat. Type in the safe display or use the keypad, then press Enter or Check guess.

1. Try a code. Enter four digits using 0–9. Digits can repeat. Type in the safe display or use the keypad, then press Enter or Check guess.

1. Try a code. Enter four digits using 1–9. Digits can repeat. Type in the safe display or use the keypad, then press Enter or Check guess.

2. Read the counts. “Right place” counts correct digits in their exact positions. “Elsewhere” counts correct digits in other positions. These are totals; they do not identify which digits matched. Each copy of a digit can match only once.

An example. If the code is 1123 and you guess 1211, the feedback is 1 right place and 2 elsewhere. This saved round retains its original rules.

2. Read each digit. A green ✓ means the right digit in the right place. Yellow ↔ means that digit belongs elsewhere. Grey × means no remaining match: the code has no unused copy of that digit. Correct positions are matched first, then other copies from left to right.

An example. For code 1123 and guess 1211, the clues are ✓ ↔ ↔ ×. The last 1 has no match left because the two 1s in the code are already matched.

3. Narrow it down. Keep every previous clue in mind. Identical guesses are rejected without using a turn. The code opens when all four digits are in the right place.

Points. Solve in three guesses or fewer for 100 points. Each guess after that reduces the score by 10, down to 50 on guess eight. An uncracked code earns 0. There is no speed bonus. The Daily result locks when solved or after eight guesses.
