# Time Drop
Ten untimed Daily event-year guesses, plus free ongoing Unlimited practice. No hearts, elimination, intro screen or speed bonus. This replaces Prior in the current lineup; Prior's source bank, IDs, files, saves and scoring stay untouched.

## Scoring v1
Each event snapshot contains a year, earliest/latest accepted years, title, explanation, topic and HTTPS source. BCE/CE counting has no year zero. An exact accepted year earns 1,000 points. Approximate intervals award full credit inside the range; errors are measured from the nearest endpoint. Outside the interval, points = max(0, round(1000 × (1 − distance / allowance))). Allowance is fixed by event era: BCE 500 years; 1–999 CE 250; 1000–1699 150; 1700–1899 100; 1900 onward 50. Scoring never changes with the current year. Native Daily score is 0–10,000; Arcade score is native points / 100. Bullseye means an exact, precise year; approximate accepted intervals say In range. On the dot requires all ten precise exact years. Completed zeroes count; partial and practice records do not.

## Content and rotation
The authoritative source is `content/time-drop-events.json`, generated with `node scripts/build-time-drop-events.cjs` into `events.js`. Its 330 distinct events include all 128 reviewed Prior events copied into new Time Drop snapshots; the original Prior files are unmodified. The 202 additions broaden time periods, regions, science, literature, games and sport. Every event has a scoped explanation and citation. Selected new claims were crosschecked against UN, British Library, NASA and Olympic records; these checks and structural validation are not a blanket independent editorial certification of all additions. A final public-launch editorial pass remains appropriate.

A deterministic era-stratified deck assigns all events to 33 sets of ten, with four or five topics per Daily in v1. Consecutive 33 Sydney dates exhaust the deck without repeating individual IDs, including across the cycle boundary. Bank order does not change selection. The epoch is 23 October 2026, repeated every 33 dates. Additional content must use a deliberate deck version; active/historical snapshots must never be regenerated. Unknown historical years must use explicit intervals rather than invented precision.

## Saves and practice
`break-room:time-drop:daily:YYYY-MM-DD` stores version/scoreVersion 1, Sydney day, ten event snapshots, current round, guessed year, committed picks, phase and edits. The first lock is final. Ten picks count as completed before opening the summary. Save on each valid input, submission and advance. Reload and mode switching retain the state. Cross-tab actions check newer progress before writing. Malformed existing saves remain untouched with a visible recovery message. Unavailable storage falls back to page memory with an honest warning.

Unlimited uses a sessionStorage namespace per guest/account owner. It resumes in the same tab across reload/mode switches, keeps session points/count and a seen-ID deck, and never enters cloud/Daily history. It excludes today's ten Daily IDs. Mixed/topic and period settings apply next event; an empty filter combination falls back to mixed rather than stranding play. A full eligible deck is reshuffled, avoiding an immediate repeat when possible, so play continues indefinitely. No record is imported from prototype `timeDropDailyV2`/`timeDropBestV2` keys. Prior records are not converted.

## Shared integration
Use the canonical Stake shell, left menu, centred title/stats/tools, Daily/Unlimited tabs, Sydney reset rail, ? help only, trapped Help/Stats dialogs and universal footer. Original era-changing artwork is retained from the archived owner prototype; the oldest artwork is labelled Early history. There is no fake sound toggle. Profile preserves native points and Arcade score; Friends returns only completed private derived scores through the existing opt-in RPC.

Existing live projects apply `supabase/time-drop.sql` after the complete Inner Clock/player-feedback update; updated `supabase/inner-clock.sql` is the complete alternative. Fresh projects use current setup then friends. The SQL helper independently validates snapshots and reconstructs scores; its execution is revoked from browser roles. Existing saves, RLS, relationships and sharing are preserved.
