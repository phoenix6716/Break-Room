# Alibi — working name

Alibi is Break Room’s seventh integrated game. Four untimed Daily office mysteries ask who did it, given one statement per suspect and an exact false-statement count. There is exactly one culprit and one logically consistent solution. The culprit may tell the truth; innocents may lie. The setting, names and item labels are not extra evidence. This is a short deduction game, not a Cluedo board with rooms and weapons.

## The seven design changes

1. **Personal notebook.** Open the notebook to mark each statement Undecided / Assume true / Assume false, and rule out or restore suspects. No checking, contradiction detector, automatic elimination or pre-answer truth feedback. Ruled-out people remain selectable. Clear notes preserves the selected accusation. Daily notes and selection persist; practice notes stay in the tab.
2. **Explicit logic.** Rules remain visible on the file; Help explains truth/false references and inclusive “at least one … possibly both”. All claims refer to whole statements. No self-reference or circular dependencies.
3. **Structural progression.** Warm-up has four suspects and direct claims; Standard has four suspects and one linked statement; Tricky has four suspects with a two-step dependency including both/either; Expert has five suspects, three linked statements and a two-step dependency. Minimum identifying cores require 3/3/3/4 statement constraints plus the given false count. This excludes accidental one-clue shortcuts. These proxies are not calibrated human difficulty.
4. **Short proof, full audit.** After the final accusation, group alternative culprits by their incompatible false counts, then identify the only matching culprit and false statements. Show full reasoning is closed initially and evaluates every statement under every possible culprit in dependency order. Truth/false and culprit labels supplement color. Continue is before the longer reasoning.
5. **Four untimed Dailies.** Warm-up → Standard → Tricky → Expert, midnight Australia/Sydney. Select then Confirm accusation; the first confirmation is final. Native score is 0–4 correct; Arcade is correct × 25, no speed bonus or retries. The fourth confirmation completes the Daily even while its review remains open. Real zeroes count.
6. **Varied Unlimited.** Free practice defaults to Changing (cycles the four tiers); optional fixed tier applies next case. It excludes today’s logical puzzles and uses the common shuffled deck. No repeats within an eligible tier until it is exhausted, then recent cases are avoided. Current case, notes, selection, review, difficulty, accuracy and best correct run survive mode switches within the tab. No practice history or cloud result.
7. **Case-file presentation.** Cream paper and folder surface, navy outlines, pastel suspect ID cards and clear sans-serif statements, with the canonical centred shell, title/stats/tools row, right reset rail, left menu, shared dialogs/footer and bottom-centred optional real sound (off by default). Reduced motion suppresses feedback movement; effects never delay the next action or replay after hydration.

## Library and source

`node scripts/build-alibi-cases.cjs` deterministically builds `cases.js`: 144 puzzles (24 Warm-up, 32 Standard, 40 Tricky, 48 Expert). They are distinct under all suspect/speaker relabelings and global truth inversion, not extra “content” made by renaming the same logic. The finite library contains no answer fields. The browser exhaustively tests every culprit/truth assignment; a separate recursive forward solver in tests and a PostgreSQL propagator independently verify the answers. Fictional office details require no factual reference claims. The original uploaded prototype is archived at `design/prototypes/alibi/original.html`, outside production.

Version 1 library IDs/seeds are stable. Never silently replace an unfinished player’s snapshots or regenerate a changed bank mid-release. New logic types or scoring rules need versioning and SQL/browser parity. Names remain provisional; change display metadata without discarding native keys.

## Integration and saves

`alibi-model.js` is pure and does not initialize engines or write storage. Prefix `break-room:alibi:daily:YYYY-MM-DD` stores `{version:1,day,edits,cases,picks,round,phase,selection,notes}`. Full cases contain id/level/n/k/s/names/crime/detail/item. Statements are `[type,a,b]` with `is`, `not`, `tru`, `lie`, inclusive `either`, or `both`; indices are zero-based. Notes use truth -1/0/1 and excluded booleans. Only the immutable picks and snapshot logic determine correctness. Claimed correct/score fields are ignored. Phase is play/review/summary; a monotonic edit counter advances same-round note/selection cloud drafts. Completed cloud snapshots take priority over later replacements, never the higher score.

Profiles, common seven-game averages, achievement Case closed (four correct), Friends, cloud allowlists, game registry, homepage, redirects and all drawers include Alibi. Previous achievement definitions remain unchanged. Share text omits culprits/statements; custom drawn text/status marks are used in the game, emoji only in clipboard text. Denied storage uses an honest memory-only warning; denied clipboard offers selectable text. Same-origin tabs adopt newer answers/notes and guard stale actions. Daily rollover keeps old results and resets the current file.

Existing Supabase installations must run **all of `supabase/alibi.sql` LAST**, after setup/Friends. It includes Pack/Prior/Laser; do not reapply their older narrower migrations. Fresh projects run current setup then Friends. The migration preserves RLS, revision checks and auth-derived ownership. Friends only receive derived bounded completed Daily scores through the existing accepted/unblocked/opt-in RPC; raw files and notes remain private. Local/mocked verification does not apply live dashboard SQL. No administrator key belongs in the client.
