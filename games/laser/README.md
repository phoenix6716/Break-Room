# Laser — working name

Four untimed Daily optical puzzles: place exactly two diagonal mirrors on Warm-up/Standard/Tricky, or three on new Expert boards, then fire the beam from the left-hand entry to a target. The first fire is final for score. A hit earns one solved board; Arcade score is solved × 25, alongside the native 0–4 result. Zero is a valid completed Daily. There are no speed bonuses, purchases or retries that improve a Daily score.

## Boards and controls

The current library has **216 boards**: the original forty each at Warm-up (5×5, two fixed mirrors), Standard (6×6, three fixed) and Tricky (6×6, three fixed, two walls), plus **96 new Expert boards** (7×7, six fixed mirrors, four walls, three player mirrors). Expert remains untimed. Its counter and instructions state the three-mirror budget.

Expert v2 replaces the repetitive mandatory entry staircase with entries across all seven rows. Every board has exactly one solution, needs all three placements, traverses at least eighteen cells and uses at least four fixed mirrors (at least seven necessary turns). Zero/one/two-mirror shortcuts are rejected. Vertically reflected duplicates are rejected too. This is a structural increase in challenge, not a measured human solve rate; further player feedback should guide calibration before adding another tier.

`node scripts/build-laser-boards.cjs` reproducibly generates the new Expert library and copies the unchanged easier tiers from `content/laser-v1-boards.json`. That source freezes **all 160 original layouts**, including old Expert boards, for compatibility testing. Never regenerate original IDs with changed layouts. New Expert IDs are `laser-v2-3-N`; v1 IDs retain their original two-mirror requirements. The outer save version and Daily seed remain unchanged. Existing drafts/reviews/completions always keep their snapshots and scores; new Expert boards appear in Unlimited immediately and in the next fresh Daily. The beam-decision solver tracks earlier empty-cell decisions and loops, and accepts every legal solution for a saved board.

Tap a square to cycle empty → / → backslash → empty. Dark mirrors are fixed; walls are striped and the target is a bullseye. Undo and Clear edit the plan before committing. The grid uses roving keyboard focus: arrows, Home/End (Ctrl for board endpoints), Enter/Space to edit. Controls remain at least 44px at 320/390/768/1100/1440 widths. Beam tracing stops on exit, wall, target or repeated position/direction. The connected SVG reveal is decorative; text reports the actual outcome. Reduced motion shows the final path immediately. Optional real sound uses the common bottom-centred off-by-default control.

After a miss, Retry opens an unscored exploration of the same board. Its mirror edits and fires are never saved over the scored pick. Show one solution demonstrates a valid path, with explicit unchanged-score wording. Players can advance immediately, including during animation. Completed Dailies offer a per-board review of their scored placement and a solution for missed boards. Reopening never plays victory effects again.

Daily uses midnight Australia/Sydney, one board from each level, and snapshots its layouts and placements. Unlimited has Mixed/Warm-up/Standard/Tricky/Expert selection applying to the next board, excludes today's Daily boards, and uses a shuffled eligible deck with repeat avoidance. Its active board, draft, first-fire review and session accuracy/best run survive mode switches within the tab. Practice does not affect Daily/cloud/profile/Friends. Unscored exploration is temporary and resets to the original scored review when changing modes or reloading.

## Save and integration contract

`laser-model.js` is pure: layout/placement validation, exact trace/solver, Daily selection and read-only records. Native prefix `break-room:laser:daily:YYYY-MM-DD` stores `{version:1,edits,day,boards,picks,mirrors,round,phase}`. Four full board snapshots include id/level/n/row/target/fixed mirrors/walls. Picks contain the board’s required number of legal mirrors (two for v1, three for v2 Expert), never claimed hit booleans. A monotonic edit counter advances cloud drafts within the same board; scored-review/completed stages still take precedence. Current drafts save on edits; phase is play/review/summary. Fourth first fire completes the Daily before the summary is opened. Reloads, bank reordering and later edits preserve valid snapshots. Same-origin tabs adopt committed results and guard against a stale second scored fire.

Scoring/profile/cloud/Friends/game registry/homepage/drawers include Laser. Existing achievement meanings remain intact; Light work requires four first-fire Daily hits. The common 120-day equal-game average now has six available games. Sharing is spoiler-free; comparisons use existing private opt-in Friends rather than answer-encoding prototype codes. Prototype local keys are not imported or erased. The uploaded original is archived in `design/prototypes/laser/original.html`, outside the production artifact.

Existing Supabase installations first complete the current `supabase/alibi-scenarios.sql` update after setup/Friends, then run **`supabase/laser-expert.sql` LAST**. If the Alibi update is already applied, only the new Expert script is needed. The new script only extends the private Laser scorer, preserves Alibi and all other games plus ownership/revision/RLS checks, and independently traces saved boards before returning only completed normalized scores to authorized friends. Never reapply older narrower per-game migrations. Fresh projects run updated setup then Friends. The existing save allowlist already accepts these snapshots, so browser/cloud play works without this scorer update. Until applied, private Friends comparisons omit new-format Laser completions; the SQL update is needed for those comparisons, not to unlock gameplay. The code/mocked tests do not apply or verify live SQL. No administrator key belongs in the client.

## Verification

`tests/laser-rules.cjs`: all 216 current boards plus all 160 originals, exhaustive independent placement enumeration (including three-mirror uniqueness and no shortcuts), all sixteen Daily hit/miss patterns, 400 seeded Dailies, malformed snapshots, zeros/partials, stable bank ordering, native cloud merge/profile behavior, actual PostgreSQL/JS parity and repeatable migration/security tests.

`tests/laser.cjs`: full real Daily at five widths, saved drafts/reviews/results, target geometry, immutable retries/solutions, copy/profile integration, practice settings/deck/isolation, keyboard/touch, modal/menu behavior, Sydney rollover, shared tabs, denied storage and manual clipboard fallback. Account tests restore actual Laser drafts on another browser, preserve user isolation and show a missing-migration error. Friends database tests include Laser at the exact comparison-window boundary and test sharing/outsider/blocking behavior.

These checks establish implementation behavior, not long-term player enjoyment, physical-phone usability or calibrated difficulty. Human playtesting is the next game-design gate.
