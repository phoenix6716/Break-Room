Style rules

  • Change tokens in break-room.css to update colours, spacing and sizing.
  • Headings use Courier New for a pixel-adjacent feel; body text uses Arial / system sans-serif for readability.
  • Keep tap targets at least 44 × 44 px.
  • Use lime for primary actions, blue for selected controls, and coral for small accents.
  • Cards collapse to two columns on mobile and the layout supports 320 px wide screens.
  • Score bands: Perfect 100, Great 85–99, Good 70–84, OK 50–69, Bad 0–49.
