The PNG is unchanged from the reviewed option; CSS clips transparent margins to match the homepage preview. Previous explorations below are retained as history. `midnight-arcade-logo-concepts.png` is a comparison board of three generated concepts:

1. **Moon Cabinet** — a crescent moon wrapping an arcade cabinet.

## Earlier selection: 02 / Midnight Marquee

The user previously selected option 2. Its archived PNGs remain in `assets/midnight-marquee-logo.png` and `assets/midnight-moon-icon.png`.

The two-line wordmark uses the cyan/magenta arcade frame, midnight clock, and yellow stars. The matching moon badge is used for the website favicon. Both assets have transparent outer backgrounds. The full wordmark replaces the former icon/text lockup on the site while preserving header placement and navigation.

The original concept board is retained as design history. The legacy SVG symbol and Lowball's own standalone game icons are retained but are not used for the Midnight Arcade header branding. The selected assets are raster PNGs, not SVG vector artwork.

## Round 2 — simpler identities under review

After seeing the first set, the user asked for a more inventive direction with less of a generic AI-generated appearance. `midnight-arcade-concepts-round-2.png` explores three restrained alternatives:

1. **After Hours** — a cyan open-door shape takes the place of the I in a custom wordmark; the companion MA symbol repeats that shape.
2. **Daily Reset** — a compact double-zero counter symbol with one yellow rollover segment, referencing fresh daily games.
3. **Still Open** — an angular A-shaped doorway with a magenta light plane, referencing a late-night arcade entrance.

These are new proposals, not selections or installed replacements. At the time of this round, the website still used the previously selected Midnight Marquee assets while the user reviewed the alternatives. No website styling, headers, or gameplay changed in this round.

## Round 3 — Moon Cabinet with printed game-title lettering

The user preferred the original Moon Cabinet idea over round 2 and requested a new logo combining it with the supplied Balatro reference's lettering style. `midnight-arcade-moon-cabinet-logo.png` retains the crescent and small arcade cabinet, with warm cream display letters, uneven baselines, dark outlines, subtle distressing, and red/cyan registration edges. It has a transparent background.

This is a new logo for review. It has not replaced the installed website assets. No gameplay, navigation, or website layout changed.

## Round 4 — three styles tested in the homepage header

The user asked for three new logos in different styles that fit the current website. Files in `logo-explorations/` are alternatives for review, with a browser-only homepage preview for each:

1. `cabinet-badge.png` — cream squared lettering, magenta offset, cyan hardware-label accents, and a crescent in the D.
2. `pixel-wordmark.png` — playful cyan/yellow pixel lettering with magenta accents; the wordmark is the identity.
3. `midnight-ticket.png` — warm admission-ticket identity with purple slab lettering, cyan trim, and a small moon punch mark.

The `*-homepage.png` images show the current desktop homepage with a temporary header substitution. Transparent padding is clipped in the browser so each design can be compared at the same existing logo-slot dimensions. The source logo PNGs are unchanged. Google Fonts were blocked during the preview capture, so the page uses its existing fallback fonts. No actual homepage, styling, navigation, or game files were edited.

Current homepage feedback to preserve for future work: the user likes a shorter single introduction, quieter effects, and clearer supporting text. Keep the existing game-card layout and keep coming-soon games together with the playable games. The user wants one universal daily reset time/countdown across all games rather than separate per-game reset displays. That timing change was pending during the logo exploration; it is now implemented by `daily-clock.js` for the homepage, Stake, Lowball, and future-game storage helpers.

## Implemented homepage refinements

The agreed homepage changes are now implemented: one compact introduction; a live universal midnight-Sydney countdown; quieter background grid/scanlines and shadows; and larger supporting text. The existing eight-card grid, its ordering, and the coming-soon artwork states are retained. The header and Cabinet Badge logo remain in place. Current screenshots are `previews/homepage-refined-desktop.png` and `previews/homepage-refined-mobile.png`.
