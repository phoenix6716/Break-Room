Contact & data help

Updated 20 October 2026

Need a hand? Start with the account and save controls below. For bugs or disputed answers, include enough detail to reproduce the problem without sharing personal information.

Game bugs and answer corrections

Use the Break Room issue tracker on GitHub to report a bug or suggest a correction. GitHub may require an account. Include the game, Daily date, browser, what happened and what you expected. For a factual correction, include a reliable source and relevant scope or units.

Issues are public. Do not include account emails, passwords, session tokens, friend codes, private messages or save-backup files. Crop personal details out of screenshots.

Account and data requests

A dedicated private support address has not been published yet. For now, you can open a GitHub issue asking the maintainer for a private contact method, without including your identity or account information. Provide any verification or personal data only after a private channel has been arranged. The public issue tracker is not a private data-request form.

This release does not have a self-service account deletion button. A maintainer with Supabase administration access must handle account deletion and broader access/correction requests. Clearing browser data or signing out does not delete your server account or cloud records.

Controls you can use now

  • Reset your password using your account email.
  • Open Account to sync/load your latest cloud saves, download a native save backup or sign out.
  • Open Friends to switch score sharing off, remove friends or block a player.
  • On a shared device, sign out and then clear the browser’s site data if you want to remove local recovery copies. Save a backup first if you need your progress.

Read the Privacy notice for what is stored, what friends can see and the limits of exports and deletion.
